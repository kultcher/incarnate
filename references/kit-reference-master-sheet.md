# BFTA Master sheet (May 2014): full transcription

Source: Google Sheet "BFTA Master" (Drive id 1IKgEPwYKhGnwY6uI3WECryVGjMUKkhIeisQd0i-k1c8), last modified 2014-05-02. The newest data in the flat-damage-era set. Transcribed verbatim, typos included. Glyphs: (Br) Bronze, (Si)/(S) Silver, (G) Gold, (So) any Soulstream card, (Bd)/(Bl) Blade-suit card. **Rec** = recharge, **Dur** = duration. *Designer note* = the sheet's own Notes column.
